Effect Size and Statistical Power Analysis

Project Overview

This project explains and demonstrates the concepts of Effect Size and Statistical Power using Python. It focuses on measuring the magnitude of differences between two groups and determining the minimum sample size required to detect statistically significant effects.

Topics Covered

- Introduction to Effect Size
- Cohen's d – Standardized Mean Difference
- Pearson's Correlation Coefficient (r)
- Interpretation of Effect Size
- Statistical Power
- Type I and Type II Errors
- Need for Power Analysis
- Factors Affecting Statistical Power
- Minimum Sample Size Calculation
- Power vs Sample Size Visualization
- ML/AI Applications of Effect Size and Statistical Power

Technologies Used

- Python
- NumPy
- Matplotlib
- SciPy
- Statsmodels
- Jupyter Notebook / Google Colab

Implementation

- Generated control and treatment group sample data.
- Calculated group means and mean difference.
- Calculated pooled standard deviation.
- Computed Cohen's d effect size.
- Interpreted effect size as negligible, small, medium, or large.
- Used the TTestIndPower module from Statsmodels.
- Calculated the required sample size for small, medium, and large effect sizes.
- Created a Power vs Sample Size graph for different effect sizes.

Key Learning Outcomes

- Understood the importance of effect size in statistical analysis.
- Learned how to calculate and interpret Cohen's d.
- Understood statistical power and hypothesis testing errors.
- Learned how sample size affects statistical power.
- Practiced power analysis using Python.
- Explored applications in Machine Learning and AI experiments.

Applications

- A/B Testing
- Machine Learning Model Comparison
- Scientific Research
- Statistical Hypothesis Testing
- Experiment Design
- Data Analysis

How to Run

1. Download the Jupyter Notebook.
2. Open "Google Colab" (https://colab.research.google.com/).
3. Upload the notebook.
4. Run all cells sequentially.
5. View the calculations, outputs, and power analysis graph.

Conclusion

This project demonstrates how effect size and statistical power help researchers make better statistical decisions. It also explains how power analysis can determine the minimum sample size needed to detect meaningful differences between groups.
